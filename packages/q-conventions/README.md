# @lab43/q-conventions

The framework conventions of [q](https://github.com/Lab43/q), an agentic coding workflow plugin for Claude Code, delivered as a q doc pack. Projects using q don't install this by hand — `/q:install-q` installs it and `/q:update-q` manages its pin. Everything else about q lives in the [q repo](https://github.com/Lab43/q).
